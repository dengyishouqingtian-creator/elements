# 四象观察者 ELEMENTS

> 理解关系，观察变化。从真实互动出发，探索行为、情绪与关系之间的联系。

**在线使用（免安装，打开即用）：https://dengyishouqingtian-creator.github.io/elements/**

一款零成本、纯前端的人物理解工具：用「水 · 火 · 土 · 风」四象框架持续记录身边人的真实行为，生成可修正的画像，而不是做一次题就给人贴标签。

## 四象体系

| 元素 | 关键词 | 含义 |
| --- | --- | --- |
| 水 | 感知与共情 | 感知情绪，理解关系 |
| 火 | 行动与表达 | 主动表达，推动行动 |
| 土 | 稳定与责任 | 稳定落实，承担责任 |
| 风 | 思考与探索 | 开放思考，探索变化 |

## 功能一览

- **人物档案**：为每位观察对象建档，管理互动信息
- **即时行为分析**：输入一句话或一件事，本地规则引擎自动匹配四象线索，命中词证据看得见
- **心情推算**：结合元素与情绪线索推算当前状态（如火象急躁、水象低落），并给出置信度
- **近期心情**：按最近记录回顾状态变化
- **分析报告**：四象分数、主/副倾向、支持证据、其他可能解释与下一步问题，结论随新记录修正
- **文献知识包**：四象知识蒸馏为结构化知识包（含校园场景表达、句式模式、修饰词标记），全部本地匹配，不调 API
- **数据总览**：人物数、记录数、主要线索分布环形图，数字全部来自本地真实记录
- **本地数据管理**：JSON 导入 / 导出备份，数据只存在自己浏览器的 localStorage，不上传任何服务器

## 使用方式

1. 打开上方在线链接（推荐用浏览器打开，微信内置浏览器请选「在浏览器打开」）
2. 点「载入示例人物A」先看效果，或「新建人物」建自己的第一个档案（请用代号，不要录真实姓名、电话、地址）
3. 在人物详情页顶部的「自动分析」输入一件事，立即得到元素倾向与心情推算，可一键存为记录
4. 记录攒够后，右侧「分析报告」会给出主/副倾向和证据
5. 定期在页面底部导出 JSON 备份（换设备/清缓存前务必导出）

## 技术

原生 HTML / CSS / JavaScript，无框架、无后端、无 API Key；GitHub Pages 静态托管；评分规则为 1/2 分制（轻度 1 分、明显 2 分），同一事件去重，推测不计分。
